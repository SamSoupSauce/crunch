# Crunch v1.6.0 — Main Menu, Brand Identity & Seamless Match Flow

Release **v1.6.0** introduces a streamlined user interface, full brand identity integration, and a clean game lifecycle loop that eliminates legacy setup screens.

---

### 🌟 Highlights & New Features

- **Brand-New Main Menu**:
  - Replaces legacy setup dialogs with an intuitive, minimalist Main Menu.
  - Dedicated **Top Navigation Bar** with direct links to the official RULES.md modal, the GitHub repository, and the developer's website.
  - Swelled high-visibility action layout: **Singleplayer** (60% width) alongside a vertical **Create Game** & **Join Game** stack (40% width).
  - Quick-access Crunchy logo in the navigation header linking directly back to home across all screens.

- **Unified Brand & Asset Overhaul**:
  - Integrated official Crunchy brand assets: `icon.svg`, multi-resolution `favicon.ico`, `logo.svg`, and `death.svg`.
  - Adopted consistent iconography and favicons across the web client, modals, victory overlay, and headers.

- **Streamlined Match Completion & State Sanitation**:
  - Deprecated and removed the obsolete "Configure Crunch Grid" setup modal.
  - Post-match victory overlay now routes directly back to the Main Menu via **"Return to Main Menu"**.
  - **Comprehensive Reset**: Exiting to the Main Menu immediately wipes stale board state, resets move history, clears the Vector Event Log, stops multiplayer polling, and restores standard starting pieces.
  - Entering Singleplayer from the menu guarantees a fresh, ready-to-play match every time.

- **Multiplayer UX Improvements**:
  - Room sharing updated to copy the raw **Room ID** directly to the clipboard with single-click confirmation ("Copy Room Code").
  - Simplified room creation and join workflows directly accessible from the Main Menu.

---
