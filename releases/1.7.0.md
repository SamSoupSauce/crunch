# Crunch v1.7.0 — Desktop Suite, Native Android & Universal Multi-Architecture Builds

Release **v1.7.0** expands Crunch across desktop and mobile platforms with dedicated native applications for Android and Electron desktop wrappers for macOS, Windows, and Linux—fully compiled and packaged across both **x64** and **arm64** architectures.

---

### 🌟 Highlights & New Features

- **📱 Native Android Application (Capacitor 8)**:
  - Official Android Studio project integrated in `android/` powered by Capacitor 8.
  - Native hardware back-button interceptor providing seamless modal closing and menu navigation.
  - Optimized viewport meta tags for modern mobile devices: edge-to-edge notch/safe-area handling, disabled bounce scrolls, and `touch-action: manipulation` for responsive, lag-free hexagonal tapping.
  - Generated official adaptive app icons across all Android mipmap densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`).
  - Automated web bundle preparation via `scripts/prepare-www.js` and CLI build commands (`npm run android:sync`, `npm run android:build`).

- **💻 Standalone Desktop Suite (Electron 34)**:
  - Native desktop wrappers for **macOS**, **Windows**, and **Linux** built on Electron 34.
  - Custom macOS frameless `hiddenInset` titlebar design with responsive traffic light spacing.
  - Native application menus for Game navigation, Singleplayer resets, Online matchmaking shortcuts (`Cmd/Ctrl+N`, `Cmd/Ctrl+M`, `Cmd/Ctrl+J`), and external rules/issue links.
  - Context-isolated architecture (`preload.js`) with sandboxed web preferences and IPC link handling.
  - High-resolution native icons for all desktop platforms: `icon.icns` (macOS), `icon.ico` (Windows), and `icon.png` (Linux).

- **⚡ Universal Multi-Architecture Support (x64 & arm64)**:
  - Configured electron-builder matrix to target both **x64** (Intel/AMD) and **arm64** (Apple Silicon / ARM Windows & Linux).
  - Standalone portable executables, installers, AppImages, and Debian packages compiled for both architectures.
  - Dedicated CLI build commands: `npm run dist`, `npm run dist:mac`, `npm run dist:win`, `npm run dist:linux`, and `npm run dist:all`.

- **🌐 Go Backend Cross-Compilation Matrix**:
  - Added multi-OS cross-compilation targets in `server/Makefile` (`make build-all`).
  - Generates standalone coordination server binaries for Darwin, Linux, and Windows on both `x64` and `arm64`.

- **🎨 Asset & Branding Refinements**:
  - Multi-resolution `favicon.ico` updated with transparent background across all resolution layers (16x16 through 256x256).
  - UI telemetry badges and main menu footer updated to `v1.7.0`.
